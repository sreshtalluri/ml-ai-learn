# Interview sprints

Seven days, 60 to 120 minutes a day, aimed at one job family. Each sprint assumes you have *some* ML background. If a lesson is new to you, read it in full; if you're reviewing, switch the website to **Quick read** (intuition, lab, summary, and interview questions only).

| Sprint | Also called | The loop leans on | Start |
|---|---|---|---|
| **ML Engineer** | Machine learning engineer, ML platform engineer | Modeling fundamentals, deep learning, ML system design, production | [ML Engineer sprint](ml-engineer.md) |
| **AI Engineer** | Applied AI engineer, LLM engineer, GenAI engineer | How LLMs work, RAG, agents, evaluation, inference cost and latency, security | [AI Engineer sprint](ai-engineer.md) |
| **Applied Scientist** | Research engineer, applied research scientist | Derivations, modeling depth, deep learning, transformers, post-training, experiments | [Applied Scientist sprint](applied-scientist.md) |
| **Data Scientist** | Product data scientist, ML data scientist | Statistics, A/B testing, metrics, classical ML, product cases | [Data Scientist sprint](data-scientist.md) |

## How every sprint day works

1. **Read** the day's lessons. Use quick read for review, full lessons for anything new.
2. **Play** with the day's labs. Make a prediction before you touch a control, then check it.
3. **Answer out loud.** Every lesson ends with an *Interview angle* section: questions real interviewers ask, with model answers. Say your answer before you open it.
4. **Drill.** On the website, the [rapid-fire drill](https://sreshtalluri.github.io/ml-ai-learn/drill/) mixes the interview flashcards and timed quiz questions for the sprint you pick. Cards you mark shaky come back later.

Day 7 is always a mock interview: a timed drill across the whole sprint, two design prompts, and a project story.

## What these sprints don't cover

Coding rounds (LeetCode-style data structures and algorithms), SQL, and behavioral interviews. Practise those separately. The "implement it" challenges at the end of each lesson do cover ML coding questions such as writing k-means, logistic regression, or attention in NumPy.
