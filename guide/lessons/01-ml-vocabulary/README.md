# Module 1: ML vocabulary and learning paradigms

Most confusion in ML comes from words used loosely: loss versus metric, parameter versus hyperparameter, training versus inference. This module fixes the vocabulary, then uses it to compare the five learning paradigms by the feedback signal each one learns from.
