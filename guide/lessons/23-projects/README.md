# Module 23: Projects and career roadmap

> **Teaching test.** You understand a concept when you can explain it simply, calculate a small example, implement it, and diagnose when it fails.

Don't wait to "finish the theory" before building. Alternate a concept, a calculation, a code experiment, and a short write-up. For every project, compare against a simple baseline and report failures honestly.
