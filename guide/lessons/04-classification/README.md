# Module 4: Classification

Classification models output a score or probability; a threshold turns that score into an action. This module covers the model (logistic regression, sigmoid, softmax, cross-entropy) and then the part that decides real-world impact: confusion matrices, precision and recall, ROC and PR curves, calibration, and class imbalance.

| # | Lesson | You will be able to |
|---|---|---|
| 1 | [Logistic regression](01-logistic-regression.md) | compute logits, probabilities, and cross-entropy by hand |
| 2 | [Classification metrics and thresholds](02-classification-metrics.md) | build a confusion matrix, compute precision, recall, and F1, and choose a threshold from error costs |
