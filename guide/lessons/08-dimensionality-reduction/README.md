# Module 8: Dimensionality reduction

High-dimensional data is hard to visualize, slow to process, and suffers from the curse of dimensionality. PCA finds the directions of greatest variance and projects onto them. Nonlinear methods (t-SNE, UMAP) make striking 2D maps that are easy to over-interpret.
