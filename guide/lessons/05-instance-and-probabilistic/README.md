# Module 5: Instance-based and probabilistic models

Three classic classifiers, each built on a different idea. KNN predicts from similar stored examples. Naive Bayes combines a prior with per-feature likelihoods using Bayes' rule. SVMs find the boundary with the widest margin and use kernels to bend it.
