# Module 18: Production AI engineering

> **Role definition.** An AI engineer combines model understanding with software engineering, data pipelines, evaluation, deployment, security, and product judgment.

| Layer | Responsibilities |
|---|---|
| Interface | API, UI, authentication, rate limits |
| Orchestration | prompt templates, routing, retries, structured outputs, tools |
| Knowledge | document ingestion, search, vector index, metadata filters |
| Model | hosted API or self-hosted inference, model versioning |
| Evaluation | offline test sets, online experiments, human review |
| Observability | traces, prompts, latency, token usage, errors, quality signals |
| Governance | privacy, access control, retention, audit, safety policies |
