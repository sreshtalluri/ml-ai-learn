# Module 7: Unsupervised learning

With no labels, the goal is structure: groups, densities, and outliers. Every method here makes assumptions about what a cluster looks like. Learn the assumptions and you will know when to trust the output.

| # | Lesson | You will be able to |
|---|---|---|
| 1 | [K-means](01-k-means.md) | run assignment and update steps by hand and choose K |
| 2 | [DBSCAN, hierarchical clustering, and Gaussian mixtures](02-density-hierarchical-and-mixture-clustering.md) | pick a clustering method by cluster shape and density, and use soft memberships |

**Interactive lab:** [K-means](https://sreshtalluri.github.io/ml-ai-learn/labs/kmeans/)

> [!IMPORTANT]
> A discovered cluster is a hypothesis, not a verified real-world category.
