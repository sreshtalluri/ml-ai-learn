# Content from AI Engineering from Scratch

This course is visual-first; [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) by Rohit Ghumare is code-first and much broader (500+ lessons). We combine them:

- **Imported** lessons are adapted into this guide's format (intuition, interactive visualization, worked math, build-it-from-scratch code, engineering, quiz, interview questions).
- **Enriched** lessons of ours take their from-scratch code and best explanations.
- Everything else useful is **linked** from the closest lesson as "Go deeper, code-first".

[`map.json`](map.json) records the decision for every upstream lesson, and [`source.json`](source.json) pins the upstream commit we copied from. Upstream content is MIT-licensed; see [the license notice](LICENSE-ai-engineering-from-scratch.txt). Each adapted lesson credits its sources at the end. Only English is maintained here.
