# Model cards

One card per model, each with the same sections: problem type, input, output, mental model, objective, training, preprocessing, assumptions, hyperparameters, good and poor use cases, strengths, weaknesses, cost, metrics, failure modes, a minimal implementation, and comparisons with neighboring models.

On the [website](https://sreshtalluri.github.io/ml-ai-learn/models/) the cards are searchable and filterable by tag.
